# File Transfers and Storage Automation with Rclone

## Overview
This repository contains the complete configuration, verification, and automation scripts for managing high-reliability file transfers between local filesystems and S3-compatible object storage using Rclone and MinIO.

## Requirements & Implementation
- Environment: Local S3-compatible storage via Dockerized MinIO (quay.io/minio/minio).
- Configuration-Free: S3 operations execute without persistent rclone.conf, using environment variables and --config /dev/null.
- Large File Reliability: Tested with 100 MB and 1 GB files, bandwidth limits (--bwlimit 25M), concurrency (--transfers 4), and interrupted transfer recovery.
- Data Safety: Tested rclone check and --dry-run deletion detection to prevent data loss during sync.
- Automation: Reusable Bash script transfer.sh supporting copy and sync, logging, and exit codes.

## Quickstart & Reproduction
1. Start MinIO:
   docker compose up -d
   (API: http://127.0.0.1:9000, Console: http://127.0.0.1:9001, User: minioadmin, Pass: minioadminpassword)

2. Configure Environment:
   export RCLONE_CONFIG_LOCALMINIO_TYPE=s3
   export RCLONE_CONFIG_LOCALMINIO_PROVIDER=Minio
   export RCLONE_CONFIG_LOCALMINIO_ENDPOINT=http://127.0.0.1:9000
   export RCLONE_CONFIG_LOCALMINIO_ACCESS_KEY_ID=minioadmin
   export RCLONE_CONFIG_LOCALMINIO_SECRET_ACCESS_KEY=minioadminpassword
   export RCLONE_CONFIG_LOCALMINIO_ENV_AUTH=false

3. Run Automated Transfer:
   ./transfer.sh ./source_dir/docs LOCALMINIO:testpress-bucket/docs/ copy
   ./transfer.sh ./source_dir/docs LOCALMINIO:testpress-bucket/docs/ sync

4. Safety & Reliability Verification:
   rclone copy source_dir/videos/lecture_recording_1gb.bin LOCALMINIO:testpress-bucket/videos/ --bwlimit 25M --transfers 4 --config /dev/null
   rclone sync source_dir/docs LOCALMINIO:testpress-bucket/docs/ --dry-run -v --config /dev/null
   rclone check source_dir/ dest_dir/

## Repository Structure
- docker-compose.yml: Local MinIO object storage service.
- transfer.sh: Reusable transfer script with dry-run safety and logging.
- commands.md: Catalog of Rclone commands with explanations.
- results.md: Experimental metrics and demo Q&A answers.
- transfer.log: Execution log generated by transfer.sh.
